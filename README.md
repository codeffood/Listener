# Listener

英语听力复读练习工具。上传或从 NAS 直接播放音频，自动用 Whisper 按句子分割，支持单句循环复读和听写模式。

## 功能

- 上传本地音频（mp3 / m4a / wav / flac / mp4 / mkv 等）
- 通过 WebDAV 直接浏览和播放 NAS 上的音频，无需下载到本地
- 用 faster-whisper 自动分句，支持 SRT 字幕优先模式
- 复读模式：单句循环 N 次后自动跳下一句，次数可设 1–10 或无限
- 听写模式：隐藏文字，点击显示
- 播放模式：单曲 / 单曲循环 / 列表顺序 / 列表循环
- 归档管理：已听完的文件可归档到分类文件夹，不占用主列表
- 所有分句结果本地缓存，重新打开无需再次转录

## 快速运行（Docker）

```bash
docker compose up -d
```

默认在 `http://localhost:8000` 打开。

数据存在 `./data/` 目录（上传的文件、分句缓存、设置），删容器不会丢数据。

## 本地运行（Python）

```bash
pip install -r requirements.txt
python -m spacy download en_core_web_sm
uvicorn main:app --reload --port 8000
```

## 设置参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| 最短句子时长 | 2.5s | 比这短的句子会合并到下一句 |
| 最长句子时长 | 12s | 超过会被拆开 |
| 重复间停顿 | 0.8s | 同一句两次播放之间停多久 |
| 句子间停顿 | 1.2s | 复读完一句跳到下一句前停多久 |
| 合并短句阈值 | 2.0s | 控制短句合并的松紧度 |
| 句尾补白 | 0.15s | 每句结束后多播多久防止尾音被截，听写练习可调到 0.25 |
| VAD 静音阈值 | 300ms | Whisper 判断停顿多久算句子边界，越大句子越少越长 |
| Whisper 模型 | base.en | tiny.en 最快，medium.en 最准（需要更多内存和时间） |

> 修改「句尾补白」和「VAD 静音阈值」后，需要对文件重新分句才生效。其他参数实时生效。

## NAS 配置

在「设置」页添加 NAS，填写 WebDAV 地址（如 `http://192.168.1.x:5005`）、用户名、密码和根目录，保存后在「NAS」标签页浏览文件。
